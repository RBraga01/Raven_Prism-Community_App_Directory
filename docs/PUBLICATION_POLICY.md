# Publication and editorial policy

This is an **independent community discovery project**, not Raven Resonance's app store, endorsed application list, software certification, security scanner or performance ranking.

## Eligible sources
- An app with a public, creator-authored page or source repository that explicitly targets Raven Prism or Raven Framework.
- Official starter examples clearly labelled as examples.
- A publicly announced prototype with its public evidence and non-installable status clearly identified (usually tracked in discovery leads until verified).

## Public data only
Record project name, author/organization, original concise description, category, public source, optional public demonstration/release.

## Excluded
No unpublished repositories, private research or testing, internal issue analyses, personal/device logs, credentials, contacts or private screenshots. Do not mirror commercial comic chapters, third-party art, audio, videos, model weights or proprietary SDK code.

## Verification and labels
- `Source code` proves a repository is publicly accessible, not that the software works.
- `Official example` identifies the origin, not a release-grade app.
- `Downloadable release` means an artifact is publicly listed, not that it is safe or device-verified.
- Do not infer physical hardware support, privacy/security status, performance or quality from readmes.
- Update claims when a source changes. Do not add star-style rankings without a published test protocol and evidence.

## Attribution and moderation
Link prominently to original creators; respect their own licenses and attribution. A listing is not permission to redistribute code, media or the Raven Framework. Treat app submissions as suggestions requiring editorial review. Issue/PR
titles are not republished in the public Google Sheet; pending suggestions are
represented only by numeric references.  Accept takedown/correction requests from project owners.

This directory is not affiliated with or endorsed by Raven Resonance.
